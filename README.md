# ORCID CV Generator

Generate beautiful, modern CVs from your ORCID profile.

## Features

- 🎨 Multiple modern CV templates
- 📄 Fetch data directly from ORCID
- ✅ Select which sections to include
- 🖼️ Optional photo upload
- 📥 Download as PDF
- 🎯 Customize each section

## Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```

## How to Use

1. Enter your ORCID ID
2. Review and select sections to include
3. Customize individual items
4. Choose a template
5. Upload photo (optional)
6. Download your CV as PDF
